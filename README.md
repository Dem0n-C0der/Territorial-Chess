# Territorial Chess v5.8.1

Cartoon-medieval strategy chess for Android. Claim land, gather resources, build your kingdom and crush the other kings!

## Features
- Turn-based chess pieces + 30 unique units with special skills
- Build Houses, Farms, Barracks, Vehicle Yards, Nukes and more
- Cars, boats and planes that carry your army
- Hidden treasures, workers, random events
- Single player vs bots (Easy / Normal / Hard / Hardcore with achievements)
- Local multiplayer (1-8 players), custom map editor
- 4 languages: English, Bahasa Indonesia, Japanese, Korean
